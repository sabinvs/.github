# AGENTS.md · org SABINVS PRODUCTIONS

Se você é uma IA lendo esta org, comece aqui.

**O que é:** a SABINVS PRODUCTIONS é um estúdio de tecnologia e entretenimento de Goiânia. O primeiro produto é o [proPosing](https://github.com/proposingapp), um coach de pose com visão computacional.

**Esta org** guarda o site institucional (repo privado) e este repo, que é público e só tem o perfil em `profile/`. Não entra aqui código, configuração nem informação interna.

**Marca:** verde `#149B5F`, verde escuro `#0E7C4A`, tinta `#0E1110`, branco e fundo claro `#F3F2F2`. Fonte: Chakra Petch.

**Trabalha para alguém do time?** O jeito de trabalhar (regras, papéis, fluxos e skills) está no kit de agentes, em `proposingapp/agentes`. Ele é privado, então o `gh` precisa estar logado na conta de um membro:

```bash
gh repo clone proposingapp/agentes
```
